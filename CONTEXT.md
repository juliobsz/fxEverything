# Fx Everything

Fx Everything helps people share social-media posts with richer previews while preserving their normal browsing experience.

## Language

**Source Link**:
The original public URL of a social-media post.
_Avoid_: Original URL, normal link

**Fixed Link**:
A shareable URL representing the same post through an embed service so messaging applications can display richer media and information.
_Avoid_: Replaced URL, modified link, proxy link

**Supported Platform**:
A social-media service for which Fx Everything can recognize supported Source Links and produce Fixed Links through both automatic sharing and explicit copying.
_Avoid_: Partially supported platform, supported network
