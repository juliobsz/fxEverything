# Privacy Policy

Effective date: July 28, 2026

FxEverything rewrites supported social-media links locally in the browser so
they produce richer previews when shared. It does not collect, transmit, sell,
or retain personal information, browsing history, website content, clipboard
contents, or usage analytics.

## Local processing

FxEverything runs only on supported pages on `x.com`, `instagram.com`, and
`www.instagram.com`. When a supported platform writes a recognized post URL
during its built-in Copy link operation, the extension removes tracking
parameters and substitutes a Fixed Link. This processing occurs locally and
the URL is not sent to FxEverything or its maintainers.

The extension does not read clipboard contents.

## Stored settings

FxEverything stores only the user's per-platform automatic-rewriting
preferences in Chrome's local extension storage. These settings remain on the
user's device and can be removed by uninstalling the extension or clearing its
stored data.

## Third-party Embed Services

Fixed Links point to independent third-party Embed Services, currently FixupX
and OGInstagram. FxEverything does not operate, control, or contact these
services while rewriting a URL.

When a Fixed Link is later shared or opened, the messaging application,
browser, or other software handling that link may contact the relevant Embed
Service. That interaction is governed by the third party's own terms and
privacy practices.

## Permissions

FxEverything requests page access only on `x.com`, `instagram.com`, and
`www.instagram.com`. This access lets it substitute recognized URLs written by
those sites.

The `storage` permission saves the two local preferences described above. The
`activeTab` permission lets the popup read the current page URL only after the
user opens the extension, for the manual **Copy fixed link for this page**
action.

FxEverything does not request clipboard, browsing-history, cookie, or all-sites
permissions.

## Changes

Any future change to FxEverything's data practices will be reflected in this
policy and disclosed as required by the Chrome Web Store policies.

## Contact

Questions and privacy concerns may be submitted through the project's public
GitHub Issues page once the repository is published. Do not include private
links, personal information, or other sensitive data in a public issue.
